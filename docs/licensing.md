## 软件代码

项目自有软件代码与软件文档使用根目录 MIT License。依赖保留其各自许可；构建器保留需要的 legal comments。软件可用、可修改，不意味着软件读到的任何金融数据都获得再分发许可。

## 人工维护数据

`data/`、主题显示名称与说明、人工备注、建议文本，以及它们生成的 JSON 数据产物，**不自动套用软件 MIT 许可，也不默认授予开放数据许可**。在维护者另行确认、公布专门的数据许可前，不将本仓库视为已经授权商用或批量再分发的数据集。

单个公开事实、原创分类判断、第三方分类体系标签、编排后的数据库，其权利性质可能不同，且受司法辖区影响。不能因为“由人工抄录”就消除原来源限制。需要公开授权时，由仓库维护者确认自己有权授权的范围，再选择合适许可；不要一键将全部外部衍生内容标成 CC0。

初始 17 条只是需求中给出的待审核示例，分类不是投资建议，也不保证准确或完整。稳定内部 ID 是本项目分配的代码，不冒充外部注册标识。

## 外部提供商

yfinance 是开源软件，但它使用到的 Yahoo Finance 数据、业务简介、持仓、商标和分类内容受提供商及权利人的独立条款约束。**yfinance 开源不等于 Yahoo 数据可任意商用或再分发。** 使用前应核对当前条款、用途、司法辖区与所需授权；本项目不替用户判断某种用途一定合法。

FinanceDatabase 的代码、仓库数据及其上游资料同样需分别核对，不能将其覆盖范围等同于使用许可。此 MVP 不复制其数据集，也不在线抓取 Yahoo。

默认只保留人工所需的简短字段、原创理由、来源链接与获取时间，不公开完整外部业务简介、原始 API 响应、实时持仓或行业权重。必要缓存保持在忽略入库的本地目录，不能因为加了来源 URL 就认为整段再分发已获许可。

公开仓库意味着任何人可能下载全部历史；私有仓库的 Pages 也未必私有。发布前同时检查数据许可与站点可见性。历史中已公开的敏感内容不能仅靠删当前文件收回。
